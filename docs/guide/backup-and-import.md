# Backup and import

## Export a backup

In **Settings → Export**, Momenthos saves your whole library as a JSON file: moments, people, shelves and tags. You can choose to include your reflections.

The backup file is **not encrypted**. Anyone who has the file can read it, so store it somewhere you trust.

A backup does not include family shelf keys or sync state.

## Import

In **Settings → Import**, choose a backup file.

- People, shelves and tags are matched by name and created if they're missing.
- Moments with the same words and date as one you already have are skipped, so importing the same file twice won't create duplicates.
- Reflections are added to their moments.

Import accepts files from the current version of Momenthos. Older backup formats may not import.

## Moving to a new device

1. Export a backup on your old device.
2. Move the file to the new device with AirDrop, Files or iCloud Drive.
3. Open Momenthos on the new device. On the last step of the welcome screens, choose **Enter & import a backup**, or use **Settings → Import** later.

Restoring a whole device from an iCloud or computer backup also restores your library.
