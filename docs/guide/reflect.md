# Reflect

Reflect is a full-screen mode for rereading past moments slowly. Open it from the **Reflect** card on Today or on a moment's page.

## A session

1. Choose what to read: for example, recent moments, a person, a tag or a shelf.
2. Optionally turn on **Begin with a breath** for about half a minute to settle first.
3. Tap **Begin**. Moments appear one at a time at a reading pace.
4. For any moment, you can add a feeling, write a thought, or just keep reading.

There's an optional timer if you want a set length. There are no scores or streaks.

## Then and Now

Each moment can have:

- One **Then** feeling: how it felt when it happened.
- Any number of **Now** reflections: how it feels when you reread it. A Now reflection needs a feeling, a written thought, or both.

A reflection can have up to two feelings. Feelings come from a fixed list of eight families (joy, connection, confidence, calm, sadness, fear, anger and discomfort), each with more specific options.

## Privacy

Reflections are private. They are never included in packages or family shelves. They are only in your own backup if you choose to include them.

You can edit or delete reflections from a moment's page.
