# Sending a package

A package is a one-time copy of some moments, protected with a passphrase. It's a good way to send a grandparent a shelf of moments.

## Sending

1. Choose the moments or shelf you want to send and pick the send option.
2. Enter a passphrase.
3. Choose how to send the file from the Share Sheet: Messages, Mail, AirDrop, Files and so on.
4. Tell the other person the passphrase separately, for example in person or by phone.

Packages never include reflections.

## Opening

Tap the `.momenthos` file on a device with Momenthos installed and choose Momenthos. Enter the passphrase. The moments are added to your library, along with their people, tags and shelves. Moments you already have are skipped.

## Things to know

- A package is a snapshot. Later changes aren't sent. For ongoing sharing, use a [family shelf](/guide/family-shelves).
- If the passphrase is lost, the package can't be opened.
